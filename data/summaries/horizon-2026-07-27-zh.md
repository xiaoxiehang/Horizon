## [微软承诺在推出新开始菜单前优化 WinUI 性能与内存](https://www.ithome.com/0/981/816.htm) ⭐️ 7.0/10

微软官方承认了 Windows 11 原生应用内存占用过高和性能问题，宣布在推出新开始菜单之前，将优先优化 WinUI 框架的内存、稳定性和性能。公司正计划将 WinUI 迁移至 Windows 系统合成器，以提升应用程序的流畅度。 这一优先级的转变表明微软正致力于解决基础性能瓶颈，而非仅仅添加新功能，这将显著改善低端硬件上的用户体验。这也标志着 WinUI 将更深地集成到 Windows Shell 中，对终端用户和开发未来 Windows 应用的开发者都将产生重要影响。 此次优化包括将 WinUI 迁移至 Windows 系统合成器，并添加数据表格（DataGrid）和图表（Charting）等新控件以鼓励开发者采用。对于即将到来的开始菜单和通知中心更新，微软目前将修复漏洞和提升响应速度置于新增 UI 功能之上。

rss · IT之家 · 7月26日 23:05

**背景**: WinUI（Windows UI 库）是微软推荐的用于构建现代 Windows 桌面应用程序的原生 UI 框架，提供 Fluent Design 设计系统和高性能渲染。从历史上看，一些使用早期 WinUI 版本构建的 Windows 11 原生应用曾因内存占用过高和性能迟缓而受到批评。

## [Decker：受 HyperCard 和经典 macOS 启发的现代平台](https://beyondloom.com/decker/) ⭐️ 6.0/10

Decker 是一个现代的独立应用程序平台，复兴了苹果传奇软件 HyperCard 和经典 macOS 的最终用户编程范式。它允许用户使用基于卡片的可视化界面创建交互式独立应用，而无需传统的软件开发工具。 该平台凸显了最终用户编程的持久吸引力，展示了易用、可视化的工具如何赋能非开发者构建功能性软件。它引发了关于用户界面演进以及当今高度碎片化的软件生态系统中独立应用程序潜力的重要讨论。 Decker 采用了令人联想到早期 Macintosh 系统的 1 位图形美学，专注于简单且将数据与界面捆绑在一起的独立卡组。虽然它捕捉到了复古计算的怀旧感，但一些用户指出，其小众的设计可能会限制其在现代主流商业应用中的采用。

hackernews · tosh · 7月26日 18:23 · [社区讨论](https://news.ycombinator.com/item?id=49060856)

**背景**: HyperCard 是苹果于 1987 年为 Macintosh 发布的开创性软件开发工具包。它引入了包含带有交互按钮的虚拟卡片的堆栈概念，并内置了名为 HyperTalk 的脚本语言，在现代 Web 出现之前很久就有效地让普通用户实现了软件创作的民主化。
